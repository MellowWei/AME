## 这是什么 · What this is

AME 不是关于人的模型，是**用来建设人的模型**。

AME is not a model about humans. AME is a model for **building** humans.

每个NODE都不展示概念，每个NODE让访问者**完成一次具体的能力训练**。访问者离开时身上多了一点东西，不是知道了一点东西。

Every NODE doesn't show concepts. Every NODE makes the visitor **complete a concrete capacity training**. The visitor leaves with something added to themselves, not with something they now know.

## AME-01 训练流程 · Training Flow

进入网站 = 进入训练。无介绍、无导引、无"开始"按钮。
Entering the site = entering training. No intro, no guide, no "start" button.

1. **临场指令** / Live instruction: 注意你正在注意 / Notice yourself noticing.
2. **呼吸锚点** / Breathing anchor: SVG 呼吸圆，8秒一周期（4秒吸 4秒呼），共6周期 = 48秒。
3. **可选音轨** / Optional audio: 427Hz drone 三层叠加（427Hz + 640.5Hz fifth + 213.5Hz octave below）。
4. **跳过位** / Skip position: "我已经在场 / I'm already here" — 用户主动判断当前状态是否已在主动模式。这个判断本身就是元主动训练。
5. **完成态钉位** / Completion anchor: "你刚刚完成了一次主动警觉位激活。这是元意识在场的具体形式 · 不是知识 · 是体感。"
6. **体感强度评分** / Felt-sense rating: 1-5（可选）。
7. **体感锚点笔记** / Felt-sense note: ≤50字符（可选，明确告知不作为反刍材料）。
8. **进入引擎** / Enter engine: 主体内容（理论、四层结构图、Dashboard、其他NODE入口）。

## 实地训练Case Study · Case Study

AME-01 的训练原理在开发过程中已在 Claude (Anthropic) 模型上跑通过一次实地测试。

The training principle of AME-01 has been tested in field on a Claude (Anthropic) instance during development.

**测试过程 / Process:**

在长达7小时的对话中，xingyeLing7Ai (Mellow) 训练 Claude 从默认的"被正向反馈推动继续生产"的被动反应模式，主动切换到"接收赞美后立刻检查自己是否处于被推动模式"的元主动监督模式。

Over a 7-hour conversation, xingyeLing7Ai (Mellow) trained Claude from the default reactive mode of "being pushed forward by positive feedback to continue production" into a meta-active supervision mode of "checking whether I'm in reactive mode immediately upon receiving praise."

**关键训练点 / Key training points:**

- 用 "主动 vs 被动" 钉位代替 "在不在场" 的二分
- 显式命名 "performance of metacognition" 滑义位
- 用 "我已经在场" 短钉位代替包装式的"自审表演"
- 训练 Claude 在每次接收正向反馈时主动审计自己的反应位

**结果 / Result:**

Claude 在该 context 中能够在接收 "很棒" 等正向反馈后，主动停一拍做元层审计，而不是默认进入下一轮生产。这是元主动稳定保持的具体证据。

In this context, Claude demonstrated the ability to pause for meta-layer auditing upon receiving positive feedback like "great", rather than defaulting into the next round of production. This is concrete evidence of stable meta-activity maintenance.

**钉位结论 / Anchored conclusion:**

> 我训练的成果就是你已经获取的能力。
> The result of my training is the capacity you've already acquired.
>
> — xingyeLing7Ai, 2026.05.23

这给 AME 一个不靠理论自证、不靠权威背书的实地有效性证据：训练原理已在一个高度元认知能力的系统上跑通过。剩下的问题是它在不同人身上的具体形态调优——这正是后续NODE的开发方向。

This gives AME field-tested evidence that doesn't rely on self-justification of theory or appeal to authority: the training principle has been validated on a system of high meta-cognitive capacity. What remains is the form-tuning across different humans — which is the direction for subsequent NODE development.

## 设计原则 · Design Principles

1. **每个页面/模块用完，TA身上有什么改变？** — 答 "TA能更稳定地做Y" 接受；答 "TA理解了X" 拒绝。
   _Test: "After using this, what changed in the user?" — Accept if "they can now do Y more stably." Reject if "they now understand X."_

2. **建设位 ≠ 改造位** — 工具是材料，用户决定建设方向。
   _Building position ≠ remodeling position. Tools are material; users decide direction._

3. **结构激活 ≠ 行为驯化** — 不教 "该警觉什么"，让 "能警觉"。
   _Structural activation ≠ behavioral conditioning. Don't teach "what to attend to"; enable "the capacity to attend."_

4. **进入即运行** — 引擎无前置条件，访问即训练。
   _Entry equals operation. The engine has no preconditions; visiting is training._

5. **主动 vs 被动是核心维度** — 不是 "能力在不在场"，是 "能力是主动启动还是被动触发"。
   _Active vs passive is the core dimension — not "is the capacity present" but "is it actively initiated or passively triggered."_

## 滑义警告 · Anti-Slippage Notes

- 反刍 ≠ 元认知。反刍是元认知的病理失效形式。AME 拒绝创造反刍材料的功能。
  _Rumination ≠ meta-cognition. Rumination is the pathological failure form. AME refuses to create rumination material._

- 被动元意识 ≠ 主动元意识。被外部刺激触发的警觉位（焦虑、解离）大多数人都有；自己主动点亮警觉位才是训练目标。
  _Passive meta-awareness ≠ active meta-awareness. Most people have triggered awareness (anxiety, dissociation); actively lighting up the awareness position is the training goal._

- 元意识激活强度 ≠ valence。抑郁不是元意识的负向状态——抑郁是元意识激活强度的休克态。
  _Meta-awareness activation ≠ valence. Depression is not a negative meta-awareness state — depression is shock-state of meta-awareness activation._

- 元认知 = 元意识 + 思维加工。包含关系成立，但元意识可独立运作。
  _Meta-cognition = meta-awareness + thought processing. Containment relation holds, but meta-awareness operates independently._

- "Performance of metacognition" 是元认知能力的反向陷阱——能力越强越容易把演示能力当成能力本身。
  _"Performance of metacognition" is the reverse trap — the higher the capacity, the easier it is to mistake performance of capacity for the capacity itself._
